PROFOLION — TEMPLATE LIBRARY HANDOFF
====================================

READ "HANDOFF_README.md" FIRST. It is the full brief.
This file is only the 5-step setup.

1. Open this "Build-Your-Portfolio" folder in VS Code.
2. Install the Kombai extension on this PC.
3. In the terminal, in this folder:

       npm install

   IMPORTANT: use "npm install", NOT "npm ci".
   The committed package-lock.json is out of sync and "npm ci" will fail.

4. Create your env file (REQUIRED before building):

       Copy-Item .env.example .env.local

   Then open .env.local and replace the two placeholders with the
   project's Supabase URL and anon key.
   (They are also in Netlify -> Site configuration -> Environment variables.)
   Without this file, "npm run build" fails on / and /templates/<id>.

5. Start it:

       npm run dev

   Then open http://localhost:3000/templates

OPEN THE DESIGN CANVAS IN KOMBAI
--------------------------------
    .kombai/canvas/profolion_templates.canvas

That one file holds all 10 designed template pages plus the spec board.
Do not move or rename it: the code links to these canvas pages, and
HANDOFF_README.md refers to each page by its node id
(e.g. "var_c72da1816899" = Grand Line).
